# 🍎 Apple iPhone 15 Pro 3D Website

A visually immersive and interactive 3D website showcasing the iPhone 15 Pro — inspired by Apple's official product page. Built with modern web technologies and 3D design tools for a smooth and premium user experience.

## 🌟 Features

- 🚀 3D animations and smooth scrolling effects
- 📱 Fully responsive layout for all devices
- ✨ Sleek, modern Apple-like design
- 🧩 3D integration using Three.js

## 🛠️ Tech Stack

- HTML5, CSS3, JavaScript
- GSAP (for animations)
- Three.js (for 3D objects)
- Vite/React
